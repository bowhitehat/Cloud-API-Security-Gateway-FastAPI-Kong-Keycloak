Ghi chú thuyết trình

  1. Web này chỉ là client. Phần chính của đề tài vẫn là API bảo mật bằng JWT và phân quyền.
  2. Swagger vẫn dùng được tại /docs.
  3. Endpoint /orders/vulnerable/{id} cố tình bị lỗi để demo BOLA.
  4. Endpoint /orders/{id} là bản đã kiểm tra owner_id và role admin.
